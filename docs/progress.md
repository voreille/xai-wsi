# Progress and results

This file records results and decisions as they come in, newest entries at the top of
each section. The plan is in the README "Research roadmap". Record W&B run ids so every
number can be traced to `runs/pathways/xai-wsi/<id>/`.

Conventions:
- TCGA-val numbers use the fixed `split_cases` split. CPTAC is used for external testing
  only and is never used for tuning.
- Report 95% bootstrap CIs over patients whenever the comparison is close.
- Result tables are generated by a script that reads the files a run writes (metrics
  CSV/JSON, checkpoints, logs), never typed or copied by hand. Put the command that
  generates a table next to it. Prefer machine-readable metric files over parsing console
  logs. Collectors check that values are in range (e.g. R² ≤ 1, Spearman in [−1, 1]) and
  fail loudly otherwise. (2026-10-23: a log-parsing collector dropped minus signs and
  reported CPTAC R² of +1.18 instead of −1.18.) Tables written before this rule are
  hand-copied; regenerate them when they are next touched.

### Does tile layout help? Predominant pattern on DHMC LUAD (2026-11-11)

DHMC LUAD (Wei et al. 2019): 143 resection slides with one predominant pattern each, no RNA
(`xaiwsi.preprocessing.dhmc.metadata`, slides from `DHMC_LUAD_corr`, which carry the mpp).
Tiled with the project tiling config (40× slides at level 0, 445 px → 224, effective
0.500–0.504 mpp), embedded with H-optimus-1 and repacked to fp16 on the host; IGNITE and ANORAK
tile probes applied with `xaiwsi.tissue.apply --cohorts dhmc-luad=<embedding dir>`. Labels are
only used for evaluation, except in the rows marked `cv:`. Three tests of whether the
arrangement of tiles carries information that composition does not.

#### ANORAK probe with neighbour context (tile level)

The linear ANORAK probe gets the mean embedding of the surrounding tiles as extra input
(`xaiwsi.tissue.probe --context`): `ring1`/`ring2` = non-overlapping neighbours within 1/2 tile
steps, `image` = all other tiles of the image, `shuffled` = as many random tiles of the image
as `ring1` would use.

Tile-composition probes, test split. Generated by:

```bash
uv run python -m xaiwsi.tissue.compare none=outputs/tissue_probe/anorak_ctx-none ring1=outputs/tissue_probe/anorak_ctx-ring1 ring2=outputs/tissue_probe/anorak_ctx-ring2 image=outputs/tissue_probe/anorak_ctx-image shuffled=outputs/tissue_probe/anorak_ctx-shuffled --output outputs/tissue_probe/anorak_ctx
```

- Counting tumour tiles beats averaging fractions: `vote` − `soft` macro AUC +0.053 (CI
  0.004 to 0.118).
- Smoothing tile pattern fractions over real neighbours changes nothing relative to no
  smoothing (balanced accuracy +0.001; macro AUC +0.006/+0.010, only ring 2 with a CI just
  above 0), and is within ±0.007 macro AUC of the same smoothing on shuffled positions. The
  balanced-accuracy gap to the shuffled rows (+0.047, CI includes 0) comes from shuffled
  smoothing pulling votes toward each slide's majority pattern, not from layout.
- Solid is easy (AUC 0.95 zero-shot, 0.89 from the TCGA-trained L2S ridge, which transfers to
  DHMC as well as to CPTAC); acinar is the weak class (AUC 0.65–0.69; 23 of 59 acinar slides
  are voted lepidic, 16 solid). Even fit on the DHMC labels, the slide mean (balanced accuracy
  0.44) is below the zero-shot tumour-tile vote (0.52).
- Caveat: tumour tiles are IGNITE tumour fraction ≥ 0.5, a median of 484 tiles per slide
  (minimum 3), about 3% of the tiles.

### NCA slide encoder on the tile grid (2026-11-06)

`xaiwsi.models.nca.TileNCAMean`: tiles placed on their slide's grid
(`xaiwsi.data.pathway.tile_grid`), projected to 32 channels, 16 hidden channels updated for T
shared-weight steps from each cell and the mean of its tissue neighbours (isotropic, so
exactly equivariant to 90° rotations and flips; off-tissue cells are dead), per-tile
readout and tile mean. Default projection: fixed PCA of TCGA-LUAD training-split tiles
(`xaiwsi.data.tile_pca`, 64 PCs explain 53% of the variance), ~20k trainable parameters.
Variants (`scripts/pathway_nca.sh`, overlay `configs/training/overrides/nca.yaml`, 3 seeds
each, W&B runs `coh-1105nca-<variant>-luad-percohort-s*`): `t0` no steps (tile MLP on the PCA
features), `t16` 16 steps (8–24 at training), `t16shuf` tiles shuffled over the tissue cells
of their slide, `t32` 32 steps (16–48), `t16lp` learned Linear+LayerNorm projection instead
of the PCA.

Takeaways:
- The fixed 32-d PCA is a bottleneck: without any spatial step it loses 0.08 CPTAC median
  Spearman against the tile mean on all 1536 dimensions (CI excludes 0).
- Spatial steps on the PCA features add +0.02–0.03 over `t0` (CIs include 0), and shuffling
  the tiles over the slide gives the same as the real layout. So far there is no evidence
  that the NCA uses the spatial arrangement; the small gain is capacity, not layout.
- With a learned projection, `t16lp` matches the tile mean on CPTAC (0.339 vs 0.342) but does
  not beat it. Without `t0` and shuffled controls for the learned projection, it is not
  known whether its steps do anything.
- Several PCA-variant runs reached their best checkpoint in the last epochs (`t16` s0 at
  epoch 29 of 30), so they may be undertrained at lr 1e-4; the learned-projection runs
  stopped at epochs 4–11.

  ±0.011 on CPTAC with CIs that include 0 (PCA at lr 1e-3 and learned projection alike).

  to CPTAC.
- Decision: the NCA line is stopped; local spatial context on frozen H-optimus-1 tile
  embeddings adds nothing measurable for bulk Hallmark scores here.

### Tissue composition and compartment pooling (2026-11-05)

Question: does knowing *which tissue* a tile shows help the slide-level Hallmark predictor?
Linear tile-composition probes on the frozen H-optimus-1 tile embeddings (IGNITE: 16
tissue classes; ANORAK: LUAD growth patterns), trained on the annotated datasets
(`xaiwsi.tissue.annotated`, `xaiwsi.tissue.probe`, metrics in
`outputs/tissue_probe/{ignite,anorak}/metrics.md`), applied to every tile of all lung
stores (`xaiwsi.tissue.apply`). The probes are references for interpretation; pathologist
labels are neither inputs nor targets of the Hallmark predictor. All probes below are ridge

slide-mean ridge).

as tile weights (`configs/tissue/compartments.yaml`): `no-background` (1 − p(bg)), `tme`
(tumour microenvironment only: background, healthy lung and other normal tissue left out),
`compartment:<c>` (B1: that compartment's mean, normalized by its own weight, so area does
not matter) and `concat` (B2: the four compartment means + shares + low-weight flags in one

Takeaways:
- Composition shares alone carry little Hallmark signal and nothing that transfers to
  CPTAC. They carry most of the growth-pattern signal (Tavernari/L2S). Adding them to the
  slide mean changes nothing: the 1536-d mean already contains them. The ANORAK solid share
  alone correlates with the true RNA L2S axis (Spearman 0.67 TCGA train, 0.60 val, 0.67
  CPTAC for L2S_TCGA; `outputs/composition_probe_tavernari/composition_correlations.csv`).
- Leaving out background and normal tissue (`tme`) barely moves anything.
- Pooling tumour tiles only (B1) is clearly better on TCGA val for Hallmarks, but not on
  CPTAC. Concatenating compartments (B2) is in between on val and equal to the slide mean
  on CPTAC. For L2S all pooled variants are within the CIs of the slide mean.
- No compartment specificity: the best compartment on TCGA val is tumour for 46 of 50
  Hallmarks (`outputs/compartment_probe/per_pathway.md`), including immune Hallmarks.
- The QC mask adds about +0.01. Flagged tiles carry under 1.5% of any pool's weight, but
  blurred/folded tiles and faded stain (not flagged by QC) leak into necrosis/inflammation,
  which fits necrosis being the weakest compartment on CPTAC.
- The slide mean stays the WSI-only baseline to beat on CPTAC.

- They are barely narrower than no model at all: width_ratio about 0.90–0.96 with `linear`
  or ridge. That is what the current accuracy implies: with a prediction–truth correlation
  ρ ≈ 0.4 the residual spread is √(1 − ρ²) ≈ 0.92 of the population spread. The best
  pathways reach 0.77–0.82 (IL6/JAK/STAT3, IFN-γ, inflammatory response, G2M, MYC V2 on
  CPTAC-LUAD). Narrow intervals need a better point predictor, not a better interval method.
- The tile model's raw predictions are mis-scaled: `constant` width_ratio ≈ 1.0 despite a
  better Spearman than ridge. Linear recalibration on val (slide-only at deployment) brings
  it to ridge's level (CPTAC-LUAD 0.92 vs ridge 0.90–0.91).
- The seed spread carries no information about the error (sigma_rho −0.004 to 0.085), so
  `ensemble` only widens the intervals. Three seeds trained on the same data disagree
  for reasons unrelated to the case.
- External coverage: CPTAC-LUAD 0.89–0.92 on average but 6 of 50 pathways under 0.8;
  CPTAC-LSCC 0.83–0.87 with 13 under 0.8 (tile luad+lusc+brca, `linear`). The misses
  are a shift of the targets, not of the model: the no-model interval misses the same
  pathways (per-pathway coverage correlation 0.97–0.98 between `marginal` and `linear`),
  and the CPTAC mean differs from the TCGA val mean by 0.5–0.96 (z units of the targets) for
  OXPHOS, ROS, DNA repair and MYC targets (`abs_bias` of `marginal` in the per-pathway CSV). These are housekeeping/metabolic programmes, so an RNA batch effect
  (TCGA vs CPTAC library prep) is a likely cause; a WSI-only model cannot correct it.
- Next: (1) separate the RNA shift from model error with a diagnostic that centers each
  cohort's targets (uses CPTAC RNA, diagnostic only); (2) better point predictions are
  what narrows the intervals (tile filtering / pooling); (3) a learned per-case scale
  (heteroscedastic head) only if a cheap signal is found to predict |residual|.

## Decisions log

- **2026-11-11:** the spatial-layout line is closed. Four tests (NCA on the tile grid for
  Hallmarks, 2 rounds; ANORAK probe with neighbour context; grid smoothing of tile pattern
  votes on DHMC; NCA trained on TCGA L2S and tested zero-shot on DHMC predominant pattern),
  each against a shuffled-position control, find no gain from tile arrangement over
  composition; the NCA is at best equal to the tile mean. `TileNCAMean`, `tile_grid` and the
  DHMC evaluation stay in the code for later checks (e.g. arrangement at larger scales). The
  slide representation stays a (weighted) tile mean. Effort goes back to what helped: more
  training cohorts, and the stage-2 options.

- **2026-10-23:** exploration aim: learn from WSI/RNA pairs something more objective
  than pathologist labels. Pattern/grade labels are used only to interpret and evaluate.
  Public pattern labels are scarce: ANORAK (quality uncertain), DHMC (kept as test), CPTAC
  dominant subtype on cBioPortal (110 cases, mostly acinar), predominant pattern in about
  50 TCGA pathology reports (TCGA-Reports OCR). Grade: CPTAC GDC `tumor_grade` (219 of
  228 cases), TCGA report text (about 300 cases), LungHist700 (45 patients, image level).
- **2026-10-23:** final goal written down: WSI-only inference of the activity of the 50
  Hallmarks, as a continuous activity with uncertainty (not a high/low class),
  interpretable at tile level. The Tavernari et al. growth-pattern gene sets are not in the
  paper's released material, so Tavernari is on hold. Hallmarks are cross-cancer, so more
  TCGA/CPTAC cohorts are an option against overfitting. RNA is training-time
  only. So RNA-side per-cohort centering on CPTAC is a diagnostic (it shows the cohort shift
  sits in the RNA embeddings), not part of the method. Shifts on the slide side can be
  corrected at test time from slides alone. Still exploratory: alignment and fusion are
  judged by how much they help the WSI-only predictor.
- **2026-10-22:** H-optimus-1 stores repacked to fp16, uncompressed, with 1024-row chunks
  (`h-optimus-1-fp16/`, `wsi-repack` in wsitools, every slide verified). The alignment
  config uses them. Stage-1 configs still point at the original fp32 LZF stores.
  Alignment training also caches decoded slides in RAM (`cache_tiles`), which made 4
  epochs take about 80 s instead of several minutes per epoch.
- **2026-10-22:** the 2c slide encoder projects tiles into the shared space before
  pooling, so tile tokens can feed the stage-4 multimodal SAE. BulkFormer gene-level
  embeddings move up in priority.
- **2026-10-22:** Hallmark scores are low-rank (participation ratio 3.7, 5 PCs = 80% of
  variance, TCGA-LUAD, scores on all samples, descriptive only). Low-rank heads and a
  frozen BulkFormer decoder head are compared before any full-embedding regression.
- **2026-10-22:** BulkFormer is used frozen with upstream preprocessing (ln TPM+1, -10
  for missing genes). The model code is vendored; `torch_sparse` is replaced by native
  `torch.sparse`.
- **2026-10-22:** survival endpoints come from TCGA-CDR (TCGA) and GDC (CPTAC). The
  primary endpoint is OS, since CPTAC has no curated PFI.
- **2026-10-22:** the slide encoder for alignment is trained on lists of whole-slide bags
  (no tile sampling), B ≈ 64. Tile subsampling is an optional augmentation experiment.
- **2026-10-22:** Hallmarks remain a WSI-only target. Fused models are evaluated on
  survival or retrieval only.
